# API Sözleşmeleri

Ajan başına dışarıya açılan uç noktalar. Detaylı akışlar için bkz. `sequence-diagrams.md`, veri modelleri için bkz. `data-schema.md`.

**Kimlik ve sahiplik (Faz B):** `/health`, `/auth/kayit`, `/auth/giris`, `/auth/eposta-dogrula` ve token'lı referans uçları (`GET /dogrulama/referans/{token}`, `POST /dogrulama/referans-yaniti`) dışındaki her uç nokta `Authorization: Bearer <token>` ister. 401 token yok/geçersiz, 403 rol uygun değil, 404 başkasının kaynağı (varlığı sızmasın diye 403 değil). Uç nokta başına kim erişir tablosu: `faz-b-kimlik-ve-dongu.md` § 3; kurallar `backend/app/api/sahiplik.py`'de.
